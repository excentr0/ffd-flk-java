# Документация по ФФД

## Какие версии существуют

- **1.0** — историческая версия: применение прекращено с **1 января 2019 года**. [Сообщение ФНС](https://www.nalog.gov.ru/rn48/news/tax_doc_news/7279364/).
- **1.05**, **1.1**, **1.2** — три актуальные версии, прямо перечисленные [ФНС](https://www.nalog.gov.ru/rn75/news/activities_fts/16639239/). Самая новая из перечисленных — **1.2**. Официальной документации по отдельной версии ФФД 1.3 в проведённом поиске не найдено.
- В том же сообщении ФНС от 24.07.2026 говорится о **планируемом**, а не уже вступившем в силу, отказе от 1.05 и 1.1 с предполагаемой датой 01.03.2027. Для решения о переходе нужно отдельно проверить принятые нормативные акты.

**Не путать:** версия ФФД и версия документа протокола — разные номера. Например, документ версии **9.8** описывает ФФД **1.05**, а не «ФФД 9.8».

## Нормативное описание реквизитов и форматов

Основной нормативный акт — **приказ ФНС от 14.09.2020 № ЕД-7-20/662@**. Форматы 1.05, 1.1 и 1.2 описываются в **приложении № 2**.

[Страница приказа ФНС](https://www.nalog.gov.ru/rn77/about_fts/docs/10020801/) · [Официальное опубликование](https://publication.pravo.gov.ru/document/0001202012100013) · [Справочная консолидированная редакция в КонсультантПлюс](https://www.consultant.ru/document/cons_doc_LAW_362322/).

- [Prikaz_662_Appendix_1_requisites.docx](Prikaz_662_Appendix_1_requisites.docx) — дополнительные реквизиты. [Источник](https://www.nalog.gov.ru/html/sites/www.new.nalog.ru/docs/about_fts/docs/pril1_ed_7_20662.docx).

**Важно:** эти DOCX — приложения, размещённые на исходной странице приказа, **не подтверждённая актуальная сводная редакция**. Для юридически значимой проверки использовать официально опубликованный акт и последующие изменения, а не считать эти вложения готовой действующей редакцией.

## Машиночитаемые данные и Java-skill

- [Структурированные данные](../README.md): JSON для 1.05 / 1.1 / 1.2, исходные поля и вложенные пути, дословные условия/формулы, кандидаты AST, ledger, схема и воспроизводимые проверки.
- [SKILL.md](../../../SKILL.md): переносимый skill со встроенной базой `references/data/`.
- [coverage.json](../coverage.json): структурный учёт и ограничения семантической готовности.

**Это черновик, не законченная формализация полного ФЛК.** В восьми группах ФД извлечены 334 / 829 / 903 контекстные записи полей; определения 110 / 138 / 185 разных тегов. Пронумерованные строки обнаруженных форматных сеток учитываются без пропусков в текущем ledger; это не доказывает полноту всего пространства тегов ФФД, всех возможных сообщений ККТ → ОФД или корректную семантику всех логических правил. Синтаксические AST не являются исполняемыми проверками. Подробности, ограничения и незакрытые вопросы — в `coverage.json` и `unresolved` каждого набора. Утверждение о полной готовности заблокировано.

## Проверка загрузок

Формат PDF проверен утилитами `file` и `pdfinfo`; целостность ZIP-контейнеров DOCX — `zipfile.testzip()`. Контрольные суммы SHA-256 исходных PDF/DOCX находятся в [SHA256SUMS.txt](SHA256SUMS.txt); ссылки на страницы загрузки сохранены выше. Исходные документы не изменялись.

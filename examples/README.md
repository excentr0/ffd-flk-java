# Проверяемые Java-механизмы, не готовый ФЛК

`NestedChecks.java` показывает подсчёт singleton внутри **одного переданного контейнера** и точный включительный десятичный допуск. Политику singleton и tolerance передаёт вызывающий код **после утверждения конкретного правила источника**. Цифры 9001/9002 и 0.01 в main — синтетические тесты, не нормативные теги/допуски ФФД.

`Field` — тестовый носитель вхождения, не модель TLV: реальные байты, длины, offsets и вложенные экземпляры нужно сохранять в модели проекта. Узел с неопределённым/пустым/нулевым значением остаётся вхождением; отсутствие узла — другое состояние. Механизм не доказывает правильность значения и не принимает фискальный документ.

```sh
javac --release 17 -d /tmp/ffd-java-example NestedChecks.java
java -cp /tmp/ffd-java-example NestedChecks
```

Ошибочные параметры/отсутствующие операнды не заменяются нулём. Обёртка валидатора должна отличать ошибку конфигурации/отсутствие контекста от нарушения конкретного ФД.

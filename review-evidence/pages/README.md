# Растры спорных страниц

Файлы `ffd-<version>-p<page>.png` — изображения соответствующих физических страниц встроенных PDF из `../../references/data/sources/`. Они сохранены для ручной перепроверки слов, границ строк и объединённых ячеек; авторитетным источником остаётся PDF.

Регенерация (пример):

```sh
pdftoppm -f 72 -l 72 -scale-to 1600 -png -singlefile \
  ../../references/data/sources/FFD_1.2_OFD-FNS_v2.15.pdf ffd-1.2-p72
```

Другие сохранённые изображения создавались с разным масштабом (до 2000 px по большей стороне); расположение строк и содержание от масштаба не зависят. OCR зависит от масштаба/раскладки; сверяй непосредственно с PDF, а не только с PNG или Tesseract.
